# Engine binary

Default path used by Sherlock:

- Symlink in this folder: `engines/lughnasadh` → `/workspace/lughnasadh-build/build/lughnasadh`
- Absolute fallback: `/workspace/lughnasadh-build/build/lughnasadh`
- Override with env: `LUGHNASADH_PATH=/path/to/lughnasadh`

Only classical UCI is spoken to this process. Do not replace with Stockfish.
